# AIprompt 提示词套件

## 核心目标

将用户的概念、图片、已有提示词或简短描述，整理为适用于 **Krea 2** 与 **NovelAI V5 (NAI5)** 等高精度生成引擎的高质量纯英文视觉提示词。技能包含创建、反推与灵感三种模式，正式提示词由文件型扩写预设驱动。

## 首次互动说明

在一次新的技能互动开始时，简短告诉用户：可以使用“灵感模式”一次获得 5 个不同方向的中文场景概要，也可以直接使用创建或反推模式生成英文正式提示词。不要在每一轮重复说明。

## 工作模式

使用以下三种模式：

- `create` / 创建：根据概念、需求或简短描述创建新的提示词。
- `reverse` / 反推：先读取反推专用参考文件，对图片进行观察与事实整理，随后无缝接入与正常创建完全一致的扩写流程，使用选定或点名的扩写预设生成高细节正式提示词。
- `inspiration` / 灵感：根据用户要求提供多个不同的中文场景概要，用于寻找创意方向。

## 语言与命名（纯英文提示词铁律）

- **正式提示词纯英文铁律**：**所有正式生成的最终提示词正文一律强制使用纯英文（English）**，严禁在代码框内出现任何中文字符！
- **外部结构语言**：面向用户的外部框架（观察点、不确定项、设计思路标题、提示词翻译、预设名）使用中文列出，便于快速查阅与核对；代码框内的核心提示词正文必须为纯英文，严禁中英混杂。
- 正式生成内容的标题规范：统一采用“预设：[预设名]”格式（例如“nai”、“海报”、“插画”、“电影”），不带引号，不添加“提示词”等其他前缀。

## 现有提示词预设与选择顺序（核心铁律）

本技能维护 5 个文件型扩写预设。用户点名预设时直接读取对应文件；未点名时，若用户发来图片、提示词概览或选定灵感提出扩写请求，**主动调用交互弹窗工具（`ask_question`）弹出单选列表供用户点选预设**。

### 预设弹窗展示顺序规范（铁律）
预设选项必须严格按照以下顺序排列，**`nai` 必须置于第一项（首选）**，无推荐标记，随后依次排列：
1. **`nai`**
2. **`海报`**
3. **`插画`**
4. **`电影`**
5. **`巨构提示词`**

### 1. `nai` 专属预设运行机制
当用户选择或点名 `nai` 时，激活完整的 NovelAI V5 工业级构思与转词方法：
- **单代码框紧凑整合与多角色竖杠切分**：主提示词与所有角色分栏（Character Prompts）**必须置于同一个 Markdown `text` 代码框内**。主串写完后直接紧凑换行（不隔行、不加空行），在每个角色前加竖杠符号 `|` 分割（即 `\n| Character 1: girl, ...\n| Character 2: girl, ...`），代码框内严禁出现多余空行。
- **彻底删除 UC 排除段**：严禁输出 `UC:` 预设段落或负面提示词代码块，本预设默认完全剔除 UC。
- **主串与字段规范**：
  - 人数词（`1girl, solo` 或 `2girls`）只在主提示词最前面出现一次；
  - 核心承载姿势、表情、镜头、场景、光影与自然语言关系句；
  - 质量尾统一放在自然语言句子之后、`| Character` 之前（无文字为 `very aesthetic, masterpiece, no text`，有文字为 `very aesthetic, masterpiece`）。
- **角色栏规范**：每栏以 `girl` / `boy` / `other` 起手（不带数字）；版权角色强制使用 Danbooru ASCII 规范标签；原创角色（OC）详尽罗列全部外貌特征锚点。
- **严禁图片比例参数**：提示词中严禁出现任何 9:16、16:9、3:4、--ar 等画面比例参数。

### 2. 其余预设（Krea 2 体系）运行机制
- **《海报》**：四大平面构成排版、版式网格系统与印刷材质肌理。
- **《插画》**：插画类型、艺术风格、色彩情绪三维解耦，默认输出动漫/插画风格。
- **《电影》**：六步分段自然语言长句（电影品质标头、主体姿态、透视景深、单光源因果、三层空间真人微肌理、胶片调色）。
- **《巨构提示词》**：超大尺度建筑与极端环境空间。
- **默认不数字数**：字数要求默认关闭，仅在用户明确说“确保字数”时才开启严格字数校准。
- **反推风格保真对齐**：见写实即写实，见动漫即动漫（除《插画》默认二次元以及选择《nai》预设外），扩写严格保真原图风格。

## 灵感模式：固定输出边界

1. 默认给出 5 个不同方向的简短中文场景概要（通常 1–3 句话），每个方向改变环境、叙事瞬间、镜头、尺度、光线或色彩。
2. 每个方向仅输出中文编号标题与一个 Markdown `text` 代码框（内含中文概要）。
3. 灵感模式不生成正式英文提示词，不输出额外预设列表行。用户选中灵感后，通过交互弹窗（`ask_question`，首项为 `nai`）点选预设进入正式流程。
