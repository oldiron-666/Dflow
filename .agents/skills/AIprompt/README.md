# AIprompt 全能提示词套件

这是一个融合 **Krea 2** 与 **NovelAI V5 (NAI5)** 体系的工业级视觉提示词生成技能，用于创建提示词、反推参考图片以及提供灵感场景概要。

## 预设矩阵与弹窗首选

技能整合了 5 个文件型扩写预设，在弹出预设选择栏时，**`nai` 始终为第一选项（首选）**：

1. **`nai`**：NovelAI V5 专属多字段一体化预设，主串与角色栏（`| Character N:`）统一置于顶端单代码框，彻底删除 UC 段，支持严谨的二次元 Danbooru 规范与空间关系句。
2. **`海报`**：平面构成、网格排版系统与印刷材质肌理。
3. **`插画`**：插画风格、色彩情绪与视觉隐喻解耦。
4. **`电影`**：电影质感、光学透视景深、真人微肌理与胶片调色。
5. **`巨构提示词`**：超大尺度建筑与极端环境空间。

## 输出格式规范

代码框包裹的纯英文提示词置于最前。随后，正式反推输出观察结果、不确定项和设计思路标题，正式创建输出设计思路标题。最后，在文末“提示词翻译：”另起一行附上不被代码框包裹的提示词中文翻译，空行与换行格式与英文正文保持严格一致。
