# DFlow

本地 Danbooru 与 Pixiv 瀑布流画廊及 AI 提示词工作流套件。

**当前版本：`0.3.8`** · [查看更新记录](改动记录.md)

本项目默认将收藏、高清缓存、登录凭据、翻译配置和自定义预设保存在本地 `data/` 目录；这些运行数据不会作为项目文件提交到 Git。

> **一句话使用**：双击运行根目录下的 `start.bat`（或执行 `npm install && npm start`），在浏览器打开 `http://127.0.0.1:4173` 即可直接使用。

## 0.3.7 本地列表缩略图与折叠公告

- 首次浏览时按需生成，最多两张并行处理，保存到私有 `data/thumbnails/`；以后复用缓存。替换或移动源文件后自动使用新的衍生图，浏览器支持缓存重验证；不支持的图片生成失败时退回原图。动图卡片显示静态首帧，点开仍查看原始动图。
- 更新公告默认折叠，展开后在独立区域滚动，保留 v0.3.0～v0.3.7 历史内容，最新版本置顶。

## 0.3.6 恢复自然卡片比例与顺序排版

- 撤回 0.3.5 的等高卡片方案。待反推与其他收藏栏一致，卡片按图片真实比例显示，横图底部操作栏、竖图侧边操作栏；不新增统一比例框架、裁切或人工留边。
- 待反推按队列顺序轮流分配到固定列，不按最短列找空位。7 列时 1～7 分别进入第 1～7 列，8、9、10 分别紧接第 1、2、3 列；暂停卡片按队列后的顺序分配，不插入 8、9、10 的横向位置之间。
- 每列按卡片实际高度独立紧凑堆叠，因此横向相邻卡片的顶部允许高低不同；不为了对齐而撑高整行或改变图片比例。图片加载、窗口缩放、移出和暂停/恢复后重新计算位置，复用未变化的卡片节点。
- 其余收藏栏的排序及紧凑排版保持不变。

## 0.3.4 修复与使用说明

### 登录

- **Danbooru**：用户名和 Personal API Key 通过 JSON 传输，兼容中文用户名；登录测试查询当前账户身份，而不是以公开图片接口是否可访问判定成功。401、403/IP 或接口权限限制、限流和网络失败分别提示。其他用户仍无法登录时，请记录登录测试显示的错误与 HTTP 状态，切勿发送 API Key。
- **Pixiv**：设置中点击「使用 Pixiv 官方登录」，在主机的 Chrome/Edge 专用窗口中使用官方页面当前提供的登录方式；DFlow 不收集密码。确认已登录后自动保存 PHPSESSID 并关闭窗口。官方第三方登录可能有浏览器/风控限制，保留手动 Cookie 作为备用；裸 PHPSESSID 值和完整 Cookie 均可粘贴。当前 Pixiv 网页接口不使用 App Refresh Token。
- 官方登录需要运行 DFlow 的电脑安装 Chrome/Edge；其他浏览器可用 `DFLOW_LOGIN_BROWSER` 指定 Chromium 浏览器可执行文件。局域网设备不能在远端打开主机登录窗口，请在主机操作或使用手动 Cookie。
- 服务端优先使用 `DFLOW_PROXY`、`HTTP_PROXY` / `HTTPS_PROXY`，Windows 下也识别系统手动代理。`DFLOW_NO_SYSTEM_PROXY=1` 可禁用系统代理检测；暂不解析 PAC。回环 MCP/API 请求绕过外部代理。浏览器能访问站点、服务端不能访问时，请确认服务端代理与网络设置。

### 画廊与补图

- **待反推**严格按统一队列编号升序显示，站点收藏和手写卡片混排；暂停/未入队项排后。暂停后重新加入队列会追加至队尾。
- **原始收藏、有词区、已完成**统一横图优先，再按提示词写入时间倒序；移入已完成不重写写词时间。旧卡片没有写词时间时依次使用有词时间、创建时间。
- 列数是用户设定的上限，按窗口可用宽度和约 228px 的最小卡宽自动收缩/恢复；缩放窗口不重新加载整页图片。
- 有词/完成跨栏移动只移除当前卡片，由按实际高度计算的小行跨度有序 Grid 紧凑补位，避免整行被最高卡片撑出大块留白；不使用会打乱视觉顺序的 dense 回填。图片加载、窗口缩放后自动重算，后台同步复用未变化的节点。减少重复模糊、轮询重绘和事件监听，保留卡片翻转及视差风格，并尊重系统减少动态效果设置。
- Agent 创建的无图提示词卡片可点击「添加图片」，在提示词编辑窗口粘贴或拖入图片后保存。仅补图不改变提示词写入时间。

### 浏览器一键批量反推

待反推栏填写可选的「本次批量反推附加要求」，点击「开始自动反推」。复用已连接的 DSH Agent 与已有聊天，不另开聊天窗口；未固定聊天时使用最近活跃且可写入的聊天。队列快照按顺序串行领取，结果直接写回卡片，浏览器显示批次进度。

**当前自动唤起仅对接 DSH Bridge**：标准 MCP 工具连接本身不能启动任意 Agent 的 AI 回合；没有桥接时明确报错，仍可在 Agent 中手动调用 MCP。队列存在未缓存图片时不跳过较早卡片，需等缓存就绪/先补图再启动。重复点击复用活动批次，不重复创建任务。

### 应用修改与验证

需要 Node.js 20.9.0 或以上。在项目目录执行 `npm install` 更新依赖，再重启 DFlow、在客户端重新连接 MCP，浏览器强制刷新。无需删除收藏、缓存、登录配置或自定义预设。

`npm test` 使用临时数据目录和独立端口验证登录错误分类、队列与排序、官方登录生命周期、MCP 重连及批量桥接；发现系统 Chrome/Edge 时还执行真实浏览器 UI 回归，没有系统浏览器则明确跳过 UI 测试。测试不访问个人收藏或替你登录真实账号。

## 功能有什么

- **双画站漫游与检索**：支持 Danbooru 与 Pixiv 随时切换，提供日榜、周榜、月榜、收藏榜、高分榜、标签检索与年龄分级筛选；Danbooru 当日日榜为空时自动显示上一日榜单并标注实际日期。
- **智能防限流与图片代理**：服务端内置请求节流（Danbooru 速率控制与 429 退避）及 Pixiv 防盗链图片代理，保障稳定浏览与防封。
- **四引擎智能翻译**：内置 DeepL、腾讯云 TMT、火山引擎、Google 翻译通道，支持二次元及成人/NSFW 词汇，支持首选与自动容灾降级。
- **本地收藏与提示词反推工作流**：
  - **原始收藏**：一键收藏喜欢的画作，所有数据保存在本地。
  - **待反推队列**：移入后后台自动串行下载并缓存高清原图，支持设置反推与扩写两阶段预设。
  - **已完成归档**：反推完成的高清原图与最终提示词永久沉淀归档，支持一键复制提示词。
  - **局部更新**：有词区与已完成区移动或释放卡片时只更新当前卡片，网格自动补位，不重建整页图片。
  - **提示词卡片文件分享**：在原始收藏、待反推、有词区或已完成中进入批量选择，可用浅绿色遮罩选择有提示词的卡片并合并导出一个 `.dflow-share.json` 文件；导入时先预览，可逐张取消，确认后才加入收藏。D/P 卡片保留站点、作品 ID、作品页和图片链接，本地手写卡片把图片原图内嵌到分享文件。
- **本机 MCP 协议支持**：内置 stdio MCP 服务（`mcp-server.js`），支持视觉 AI Agent 自动读取待反推本地原图并写回扩写提示词；待反推卡片支持「AI直推」，可把单图任务排队到指定的在线 Agent。
- **ComfyUI / SD 原图元数据解析**：秒级解析原生 PNG 格式图片，自动提取底模 Checkpoint、LoRA 名称与权重、采样器、步数、Seed 及正反向提示词。
- **局域网多端同步**：同一 Wi-Fi 下手机、平板输入电脑局域网 IP（`http://<电脑IP>:4173`）即可同步浏览与操作。

## 怎么用

### 1. 启动服务
- **Windows 一键启动**：双击运行 `start.bat`。
- **命令行启动**：
  ```bash
  npm install
  npm start
  ```
  启动后在浏览器打开 `http://127.0.0.1:4173`。

### 2. 浏览与检索
- 点击左上角 `D` / `P` 按钮切换当前站台（Danbooru / Pixiv）。
- 顶部搜索框直接输入标签（Tag）或画师名进行搜索。
- 点击导航栏榜单按钮可按日热门、周热门、月热门或最新作品浏览。

### 3. 收藏与提示词反推
1. **收藏画作**：点击卡片上的心形图标存入「原始收藏」。
2. **移入待反推**：点击卡片上的 `AI` 按钮，后台会自动下载高清原图并加入待反推队列。
3. **执行反推**：
   - **通过 MCP**：在支持 MCP 的 Agent 中配置本机 MCP（详见 [MCP.md](MCP.md)），Agent 可自动逐张读取待反推高清图并写回提示词；也可以直接点击待反推卡片上的「AI直推」，将单张图片提交给已连接的 Agent。
   - **通过命令行**：使用 `node scripts/reverse-cli.mjs` 领取任务并写回。
   - **手动填写**：在待反推卡片中直接编辑正向提示词。
4. **释放归档**：提示词就绪后点击 `→` 按钮释放至「已完成」，高清原图与提示词永久归档。

### 4. 提示词卡片分享与导入

- 只有已经写入提示词的卡片可以被批量选择或右键分享；选择范围只限当前本地收藏分栏，切换分栏会自动退出选择模式。
- 批量分享只生成一个 `.dflow-share.json` 文件，文件内容包含提示词和必要的来源信息：D/P 站类型、作品 ID、作品页链接、图片链接、标题/作者等。
- 本地手写卡片没有可靠的远程图片地址，因此会把当前本地原图内嵌进分享文件；D/P 卡片不重复嵌入本地缓存，而是由接收端按链接获取图片。
- 导入不会立即写入：先打开预览窗口，可逐张取消，点击「确认加入收藏」后才真正导入。D/P 卡片仍按对应站点收藏保存，本地卡片进入有词区。
- 接收端使用确认加入收藏的时间作为新的提示词写入时间，不带入分享者的原始时间；分享文件不包含 `data/`、高清缓存目录、密钥、Cookie、翻译密钥或本地自定义预设。

### 5. ComfyUI 图片参数提取
1. 进入顶部「元数据库」页面。
2. 点击「导入 ComfyUI PNG」或拖入由 ComfyUI / WebUI 生成的原始 PNG 图片。
3. 系统自动提取模型、LoRA、生图参数及正反向提示词，点击即可一键复制。

### 6. 账号凭据与翻译配置
点击顶部导航栏右上角的「登录/设置」图标：
- **画站凭据**：填入 Danbooru API Key 或 Pixiv Session Token，解锁免登录与高清浏览限制。
- **翻译配置**：填入 DeepL / 腾讯云 / 火山引擎的 API Key（Google 翻译免密直接可用）。
- **MCP 与预设管理**：查看已连接的 Agent，管理反推预设与扩写预设。

### 7. 常用快捷键
- `Ctrl + 滚轮`：自由调整卡片排列列数
- `Ctrl + Z`：快速撤销操作
- `鼠标左键`：呼出高清大图预览
- `鼠标右键`：呼出操作菜单（创建卡片、复制原图、复制直链、删除等）
- `Esc`：关闭大图预览浮层
