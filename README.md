## 一、项目简介

**DFlow** 是一个轻量级、响应迅速且功能完备的二次元画作与艺术作品本地瀑布流浏览器。不仅为海量插画提供类似 Pinterest 的沉浸式无限滚动浏览，更深度融合了现代 AIGC（AI 生成艺术）创作者的刚性需求——**将优质灵感图片直接转化为高质量生成提示词（Prompts），并能无缝解析 ComfyUI / SD 生成参数。**

随着全新版本的迭代，系统全面引入了 **Pixiv（Pflow）模式** 与 **四引擎智能翻译中枢**，完成了由单一站台工具向全能型灵感中枢的跨越。

### 💡 核心价值
- **双站合一，沉浸切换**：左上角 3D 立体翻转胶囊一键在 Danbooru (Dflow) 与 Pixiv (Pflow) 间无感切换，各自独立检索，全局统一收藏。
- **高可用抗封杀翻译**：内置 DeepL、腾讯云 TMT、火山引擎、Google 四大翻译通道，专门攻克色情/NSFW 与二次元俚语机翻被风控拦截的痛点，支持自动容灾降级。
- **保护隐私，独立存储**：收藏与标签不依赖远端账号，所有收藏、偏好与提示词均完整保存在本地 JSON 与磁盘目录。
- **打通 AIGC 工作流**：从“刷图看到心动作品”到“移入待反推”、“AI 自动逆向提示词”、“归档已完成库”，再到“导入本地 ComfyUI 图片提取底模、LoRA 与生图参数”，形成完整生产力闭环。
- **零构建、轻量化**：基于原生 Node.js ES Module 与原生前端构建，启动仅需数秒，内存占用极低。

## 二、核心特性深度解析

### 1. Dflow ⇄ Pflow 双站无缝切换与极速漫游
- **3D 翻转胶囊切换**：左上角设有立体金属质感切换按钮，点击伴随平滑 3D 翻转动效，瞬间在 **Dflow（Danbooru 站）** 与 **Pflow（Pixiv 站）** 之间自由漫游。
- **独立站台体系**：
  - **Dflow**：日榜、周榜、月榜、收藏榜、高分榜、标签探索、四级年龄分级筛选；
  - **Pflow**：全站综合日榜、插画日榜、周榜、月榜、新人画师榜、R18 成人榜、R18-G、AI 作品专属开关；
- **公用核心资产**：
  - **本地收藏**、**元数据库** 与 **全局搜索框** 跨站保持一致，不会因切换站台而割裂；
  - 切换到 Pixiv 时，顶部通用搜索框自动接入 Pixiv 标签与作品检索。

### 2. 全新黑曜石暗黑玻璃态 UI 与精雕卡片布局
- **黑曜石玻璃态设计（Obsidian Dark Glass）**：
  - 深度优化的暗夜高保真视觉体系，半透明亚克力磨砂毛玻璃（Frosted Glass）质感，降低长时间刷图的视觉疲劳。
  - 桌面端默认 **5 列黄金排版**，支持自适应动态缩放与自由调节。
- **卡片图源与分级角标**：
  - **图源标识**：本地收藏区卡片左上角配有精致圆形胶囊徽章（`D` 标识 Danbooru，`P` 标识 Pixiv）；
  - **分级圆点**：卡片右上角保留年龄分级圆点（全年龄/敏感/较敏感/成人）。
- **非图片内容区操作栏重构**：
  - 将操作按钮统一移至非图片信息区，杜绝按钮与插画主体叠层遮挡；
  - **横版图片**：宽幅展示，按钮居中横排分布在复制按钮下方；
  - **竖版图片**：修长展示，按钮优雅竖排；
  - **标准统一按键序列**：`[ AI ]`（移入待反推） ➔ `[ → ]`（释放至已完成） ➔ `[ ♥ 收藏 ]`；
  - **智能排版算法**：有词区与已完成专栏采用“横版宽图置顶、竖版紧随其后、按时间倒序”的高级瀑布流排列。
- **极简卡片右键菜单**：
  - 移除了突兀易误触的常驻红色删除图标，卡片删除集成至右键菜单并提供二次确认；
  - 右键支持：创建提示词卡片、加入/取消本地收藏、复制高清图片（PNG 原生转码）、复制原图直链、在新标签页打开。

### 3. 四引擎智能翻译中枢 (支持二次元与成人词汇)
AI 绘图及二次元领域大量涉及敏感姿态、服装细节与成人向（NSFW）提示词，传统免费翻译接口极易触发内容审查封禁或返回空文本。为此，系统研发了多引擎高可用翻译中枢：

- **四大引擎无缝集成**：
  1. **DeepL 翻译**：语义精准，语法逻辑出众，外语长句翻译极佳；
  2. **腾讯云 TMT**：国内极速响应，专线稳定，每月提供高额免费字符额度；
  3. **火山引擎 (字节跳动 Volcengine)**：强大的本土化模型，对俚语、ACG 术语理解深厚；
  4. **Google 翻译**：免配置默认基础通道，适合快速尝鲜。
- **NSFW / 成人词汇穿透**：通过专业引擎的官方商业 API 接入，彻底解决色情与成人词汇被中间层审查拦截的问题。
- **智能故障转移（Auto Failover）**：
  - 用户可在设置中指定首选引擎；
  - 当首选引擎遇到网络超时、配额耗尽或返回异常时，系统自动无感降级尝试备用引擎，确保工作流永不中断。
- **局部与全量提示词同步**：
  - 支持中英文双向同步编辑；
  - 提示词窗口右侧内置翻译对照面板，按需局部修正，点击“修正翻译”即刻增量翻译并同步。

### 4. “近一个月”聚合算法与双站多维榜单
Danbooru 官方 API 对于无时间限制的全站级排序（如总收藏榜、总评论榜、总分榜）经常因庞大的数据量导致数据库查询超过 15 秒并触发 HTTP 500/504 错误。DFlow 创新性地设计了时间窗口与服务端降级机制：

- **近一个月窗口聚合机制（1-Month Windowing）**：
  - 针对 **收藏（favcount）、评论（comment）、点赞（upvotes）、高分（score）、趋势（rank）、超大图（mpixels）** 这 6 大聚合榜单，自动注入 `age:<1month order:...` 查询限制。
  - 既完整呈现了近期社区中最热门作品，又彻底根除了全站聚合查询超时问题。
- **全方位榜单覆盖**：
  - **最新（Latest）**：使用 Danbooru 的游标机制（`b{id}`），实现真正意义上的无限向后回溯刷图；
  - **日热门 / 周热门 / 月热门（Popular Day/Week/Month）**：官方多周期 Explore 热门榜；
  - **Pixiv 多维榜**：日榜、周榜、月榜、新人榜、R18 榜单自由穿梭。
  - **服务端自动候选降级**：当宽泛的 `order:score` 查询超时，服务端自动无缝追加 `status:active` 过滤重试，杜绝整页空白。

### 5. 本地三栏收藏与有词区闭环工作流
本地收藏不往远端同步，保存在本地服务端磁盘；同一局域网设备可共享。

```text
[日常刷图] ──♥ 收藏──> 【原始收藏 (Original)】
                             │
                      [AI] 移入待反推
                             │
                             ▼
                    【待反推 (Pending)】
                    ┌───────────────────────────┐
                    │ 1. 后台串行自动缓存高清原图 │
                    │ 2. 选择反推预设风格       │
                    │ 3. 外部 Agent/Codex 批量反推│
                    │ 4. 写入提示词 (Prompt)    │
                    └─────────────┬─────────────┘
                                  │
                               [ → 释放]
                                  │
                                  ▼
                    【已完成 (Completed)】
                    (高清图与优质提示词永久沉淀)
```

- **第一栏：原始收藏 (Original)**：
  - 刷图时点击卡片心形图标即可沉淀到此；
  - 卡片集成 **AI** 按钮（移入待反推）与 **释放至已完成** 快捷按键。
- **第二栏：待反推 (Pending)**：
  - **后台高清图异步缓存**：一旦移入，Node 服务在后台缓存高清原图到本地 `data/favorites/pending/` 目录；
  - **反推预设体系**：内置 **通用扩写、动漫专用、动作扩写、艺术导演扩写、巨构提示词、瑶光真人、随机** 等丰富预设；
  - **队列管理**：支持卡片加入/移出反推队列（`autoEnabled` 开关与 `queueOrder` 严格编号）；
  - **状态灯指示**：红灯（缓存/反推失败，点击即刻重试）、绿灯（反推成功）、黄/灰色（排队与缓存中）；
  - **安全“释放”机制**：只有当“高清原图已本地缓存”且“提示词反推成功”后，“`→` 释放”按钮才会激活。
- **第三栏：已完成 (Completed)**：
  - 最终归档库，展示高清原图与高质量反推提示词；
  - 支持一键复制提示词、弹窗查看全文，随时可逆回退到原始收藏。

### 6. ComfyUI 图片元数据提取与参数复用
DFlow 内置专属的「元数据库 (Metadata)」模块，彻底解决 AI 创作者“看到一张图不知道工作流怎么搭”的痛点：

- **纯原生二进制解析（零额外依赖）**：
  - 底层基于 Node.js 原生 `Buffer` 与 `node:zlib.inflateSync`，秒级解析 PNG 的 `IHDR`、`tEXt`、`iTXt`、`zTXt` 关键数据块，单张最大支持 **80MB** 超大图导入。
- **深度兼容与智能解析**：
  - **ComfyUI API 拓扑解析**：递归遍历节点连接树（Link Traversal），顺藤摸瓜定位到与 KSampler 直接或间接绑定的 CLIPTextEncode 正反提示词输入节点。
  - **ComfyUI Workflow 解析**：智能从各节点的 `widgets_values` 中提取采样器、步数与模型名。
  - **A1111 / SD-WebUI 兼容**：兼容解析经典 SD-WebUI 的 `parameters` 文本格式。
  - **LoRA 强力侦测**：全面支持标准 `LoraLoader`、`LoraStacker`、`Power Lora Loader` 等多种主流 LoRA 加载节点的名称与权重（Strength）提取。
- **结构化参数一览**：
  - **底模（Model）**：Checkpoint 名称、UNET 名称；
  - **LoRA 清单**：展开折叠显示各 LoRA 名称及模型权重；
  - **生图核心参数**：步数 (Steps)、CFG Scale、采样器 (Sampler)、调度器 (Scheduler)、随机种子 (Seed)、降噪幅度 (Denoise)；
  - **提示词操作**：正反向提示词查看、一键复制、原图放大与本地删除。

### 7. 局域网多端同步与跨设备协同
- **主机运行，全屋共用**：电脑启动服务后，同一 Wi-Fi / 局域网内的手机、平板、笔电直接通过浏览器打开 `http://电脑局域网IP:4173`。
- **统一数据中枢**：服务端统一维护 `data/dflow-state.json`，多设备共享同一份收藏夹、站台凭据、翻译 API 与浏览偏好。
- **即时与增量轮询机制**：本机修改即时写入；其他已打开的设备每 10 秒轻量级增量对比 `updatedAt` 时间戳，发现变化无感刷新同步。
- **端设备自适应响应式**：手机端自动单/双列自适应排版，大屏电脑端支持宽屏多列并排；内置移动端适配层 `public/mobile-adapter.js` 与独立离线执行支持。

---

### 8. 智能抗限流与双通道图片代理
- **服务端防封节流（Paced Fetch）**：
  - Danbooru 对接口并发有严格的限流策略。DFlow 服务端设计了串行请求队列，默认保证 1800ms 的安全请求间隙。
  - 遇到 HTTP 420 / 429 限流时，智能解析 `Retry-After` 头，并使用指数退避算法进行熔断冷却，防止 IP 被封。
- **图片专用 CDN 4 并发槽位**：
  - 设立了独立的图片代理通道（最多 4 并发），平滑请求速率并设置 24 小时缓存头。
  - 针对 Pixiv 的防盗链机制，服务端代理自动抹除/伪造 `Referer` 请求头，确保 Pixiv 插画流畅直连加载。

## 三、技术栈与系统架构

### 1. 技术栈选型
- **后端运行环境**：Node.js (>= 18.0.0, ES Module 原生模式)
- **服务端框架**：Express 5.x（极简 HTTP 路由、静态托管、流媒体代理、多翻译引擎中继）
- **核心底层库**：`node:fs`、`node:path`、`node:crypto`、`node:zlib`（原生 PNG 解压与元数据提取，无任何重型图像第三方 C++ 依赖）
- **前端架构**：原生 HTML5 + 现代 Vanilla JavaScript + 原生 CSS3 Flex/Grid（黑曜石暗黑玻璃态，无打包构建负担）
- **数据持久化**：本地 JSON 文件存储 (`dflow-state.json`, `index.json`) + 磁盘图片文件目录结构

## 四、安装启动与配置指南

### 1. 环境要求
- **操作系统**：Windows / macOS / Linux
- **运行环境**：[Node.js](https://nodejs.org/) `>= 18.0.0`
- **网络条件**：能正常访问对应画站的网络环境（必要时可在主机配置代理客户端）

### 2. 一键启动 (Windows)
在项目根目录下，双击运行 **`start.bat`**。
脚本会自动检测并执行 `npm install`，随后拉起默认浏览器访问 `http://127.0.0.1:4173`。

### 3. 命令行安装与启动
```bash
# 1. 进入项目目录
cd dflow

# 2. 安装极简依赖 (仅 express)
npm install

# 3. 启动本地服务
npm start

# 开发模式 (Node 18+ 原生文件监听热重启)
npm run dev
```

### 4. 站台凭据与配置 (Danbooru / Pixiv)
点击顶部导航栏右上角的 **「登录」** 图标（在 D 站模式下显示为 Danbooru 登录，在 P 站模式下显示为 Pixiv 登录）：
- **Danbooru 凭据**：
  - 点击弹窗内的直达链接前往 [Danbooru API Keys 页面](https://danbooru.donmai.us/profile) 获取；
  - 填入用户名与 API Key，点击“测试并保存”；
- **Pixiv 凭据**：
  - 点击弹窗内的直达链接前往 Pixiv 登录；
  - 填入 Pixiv Session / Refresh Token，享受突破免登录浏览与清晰度限制。

### 5. 翻译引擎 API 获取与配置指南
点击顶部导航栏的 **「设置」** 图标，进入多引擎翻译中枢配置面板：
- **DeepL**：前往 [DeepL API 控制台](https://www.deepl.com/pro-api) 免费注册获取 Auth Key（支持 Free 与 Pro 密钥）；
- **腾讯云 TMT**：前往 [腾讯云机器翻译控制台](https://console.cloud.tencent.com/tmt) 获取 SecretId 与 SecretKey（每月数百万免费字符）；
- **火山引擎 (字节跳动)**：前往 [火山引擎机器翻译控制台](https://console.volcengine.com/translate) 获取 AccessKey ID 与 Secret AccessKey；
- **Google 翻译**：无需配置密钥即可直接作为基础兜底通道。

各输入框旁均提供了**一键直达申请页面**链接与**连通性测试**按钮，配置完成后即刻生效。

### 6. 局域网访问与远程穿透
- **同一局域网访问**：
  1. 终端输入 `ipconfig` (Windows) 查看局域网 IP（例如 `192.168.1.100`）；
  2. 手机或平板连接同一 Wi-Fi，访问 `http://192.168.1.100:4173` 即可跨设备同步。
- **免公网 IP 远程穿透（Cloudflare Quick Tunnel）**：
  ```bash
  cloudflared.exe tunnel --url http://127.0.0.1:4173
  ```
  终端生成的临时公网地址打开即可随时随地远程访问。

### 本机 MCP、两阶段预设与 Agent 管理

DFlow 提供本机 stdio MCP，供一个视觉 Agent 逐张处理待反推区；它**不自行调用 AI 或自动识图**。在顶部「登录 Dflow / Pflow」→「MCP 设置」（位于翻译引擎配置后）可复制当前电脑的连接 JSON，查看连接中的 Agent 并断开当前会话。先运行 `npm start`，再将配置粘贴到 Agent 客户端；具体工具与参数见 [MCP.md](MCP.md)。会话列表/断开仅在运行 DFlow 的电脑上可用，不是远程 Agent 控制台。客户端若自动重连，断开后可能再次出现。

反推采用固定顺序：**读取待反推本地高清图 → 反推预设（观察、区分事实与推测）→ 扩写预设（生成最终提示词）→ 写回有词区**。MCP 的 `claim_next_pending` 会附带本图两阶段的完整流程和预设内容；还提供 `get_reverse_workflow` 工具及 `dflow_reverse` MCP prompt。错误会留在待反推区并显示原因。待反推卡片分别有反推和扩写两个下拉；预设可在 MCP 设置中新增、粘贴/导入 `.txt` 或 `.md`、编辑、删除及设置默认。修改后点击「保存预设」才生效。

GitHub 仓库只附带 `presets/通用扩写.txt` 这一种**扩写预设**；内置的通用反推流程写在 `reverse-workflow.js`。你在设置中管理的其他预设保存在被 `.gitignore` 排除的 `data/mcp-presets/`，**不会随 Git 上传**。当前本机的 1 个反推预设和 6 个扩写预设仅来自 `D:\Download\Documents\krea2-prompt-suite.zip`，通用反推为 ZIP 中的 V2 版，换电脑需自己备份/复制。旧的 CLI 方式仍可使用，但不会提供 MCP 的完整两阶段预设正文。

### 2. AI 提示词反推自动化流程 (搭配 Krea2 Skill)

1. **移入待反推**：刷图时点击卡片非图片区的 **`AI`** 按钮移入「待反推」；
2. **后台缓存大图**：服务端在后台串行下载高清原图至 `data/favorites/pending/`（卡片亮黄灯/绿灯指示）；
3. **唤醒 AI 助手执行反推**：
   - 推荐使用本机 MCP 的 `list_pending`、`claim_next_pending`、`read_pending_image`，先执行反推预设，再执行扩写预设；
   - 原命令行方式仍可用：搭配配套 Skill，AI Agent 运行 `node scripts/reverse-cli.mjs status` 探测队列；
   - 逐张调用 `node scripts/reverse-cli.mjs next` 领取任务；
   - 观察本地高清缓存图，严格区分客观事实与合理推测，生成高质量扩写提示词；
   - 调用 `node scripts/reverse-cli.mjs complete <ID> <PROMPT_FILE> 通用扩写` 回写系统；
4. **释放至已完成归档**：
   - 提示词就绪后，点击卡片上的 **`→` 释放** 按钮，系统自动将高清缓存大图迁移至 `data/favorites/completed/`，完成永久归档。

### 3. 有词卡片、手写与翻译工作区
- **创建与手写**：对任意画作右键选择「创建提示词卡片」，或点击顶部「手写提示词」，可拖入本地图片或仅录入文本；

- **实时局部翻译**：展开卡片后，编辑英文提示词可按需点击「修正翻译」，自动经由配置的多引擎中枢进行双向精准翻译。

## 六、注意事项与常见问题

> [!IMPORTANT]
> **关于图片导入**：ComfyUI 元数据提取功能依赖于 PNG 文件内置的元数据块。从各大社交平台转存的图片通常已被压缩转码并剔除了生成信息，请务必导入原始 PNG 文件。

> [!NOTE]
> **剪贴板兼容性**：操作系统与浏览器 Clipboard API 原生支持 `image/png` 格式。当你在 DFlow 中复制画作时，系统已内置 Canvas 内存转码，将图片自动转换为标准 PNG 格式后再推入剪贴板。

> [!WARNING]
> **本地数据安全**：所有配置、凭据与收藏均保存在本地 `data/dflow-state.json` 中。请注意定期备份 `data/` 目录；切勿将 `data/` 目录上传至公开代码仓库或分享给他人。
