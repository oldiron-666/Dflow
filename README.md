## 一、项目简介

**DFlow** 是一个轻量级、响应迅速且功能完备的 Danbooru 本地瀑布流浏览器。它不仅为二次元画作与艺术作品提供类似 Pinterest 的沉浸式无限滚动浏览体验，更深入融合了现代 AIGC（AI 生成艺术）创作者的实际需求——**将优质灵感图片直接转化为高质量生成提示词（Prompts），并能无缝解析 ComfyUI / SD 生成参数。**

### 💡 为什么选择 DFlow？
- **告别卡顿与超时**：针对 Danbooru 经常出现的宽泛全站聚合查询超时问题，创新性地设计了时间窗口与服务端降级机制。
- **保护隐私，独立存储**：收藏与标签不写入 Danbooru 远端账号，所有收藏、偏好与提示词均完整保存在本地 JSON 与磁盘目录。
- **打通 AIGC 工作流**：从“刷图看到心动作品”到“移入待反推”、“AI 自动逆向提示词”、“归档已完成库”，再到“导入本地 ComfyUI 图片提取底模、LoRA 与生图参数”，形成完整生产力闭环。
- **零构建、轻量化**：基于原生 Node.js ES Module 与原生前端构建，启动仅需数秒，内存占用极低。

## 二、核心特性深度解析

### 1. 极致流畅的无限瀑布流浏览
- **动态列高计算（Masonry Layout）**：前端采用实时高度堆叠算法，图片卡片始终智能插入到当前高度最短的列中，保证页面布局严丝合缝，不出现高低断层。
- **自适应视口与平滑缩放**：
  - 默认支持 **3 ～ 8 列** 动态调节。
  - **快捷键联动**：支持 `Ctrl + 鼠标滚轮` 实时增减列数，滚轮向下滚动列数减少、图片自动放大，大屏看细节更震撼。
- **就近预加载与防抖**：采用原生 `IntersectionObserver` 监听底部哨兵元素（Sentinel），在距离底部 1200px 时静默触发下一批加载，配合 `img loading="lazy"` 与 `decoding="async"`，滚动丝滑不卡顿。
- **原图比例高清浮层（Lightbox）**：点击任意卡片即可在侧边展开高清预览面板，自动计算屏幕黄金比例与最佳可视面积，不遮挡核心内容，轻点即关。
- **右键高级上下文菜单**：
  - **加入/取消本地收藏**；
  - **复制高清图片**：前端内置 Canvas 内存转码，将 WebP / JPEG 自动无损转换为系统剪贴板原生支持的 PNG 格式后写入剪贴板；
  - **复制原图直链 / 新标签页打开**。
- **智能视图恢复（View Cache）**：内置最多 30 个维度的 LRU 视图状态缓存，切换榜单、分级或标签后返回，瞬间恢复先前的滚动位置、分页游标和当前图片流，免去重复加载烦恼。
- **全局撤销（Undo Stack）**：支持 `Ctrl + Z` 全局快捷键，无论是误取消收藏、误移动文件夹还是误标记完成，均可一键撤销。

### 2. “近一个月”聚合算法与多维榜单
Danbooru 官方 API 对于无时间限制的全站级排序（如总收藏榜、总评论榜、总分榜）经常因庞大的数据量导致数据库查询超过 15 秒并触发 HTTP 500/504 错误。DFlow 为此做出了关键架构优化：

- **近一个月窗口聚合机制（1-Month Windowing）**：
  - 针对 **收藏（favcount）、评论（comment）、点赞（upvotes）、高分（score）、趋势（rank）、超大图（mpixels）** 这 6 大聚合榜单，自动注入 `age:<1month order:...` 查询限制。
  - 既完整呈现了近期社区中最热门、最具有前沿参考价值的顶尖作品，又彻底根除了全站聚合查询超时问题。
- **全方位榜单覆盖**：
  - **最新（Latest）**：使用 Danbooru 的游标机制（`b{id}`），实现真正意义上的无限向后回溯刷图。
  - **日热门 / 周热门 / 月热门（Popular Day/Week/Month）**：官方多周期 Explore 热门榜。
  - **日浏览榜（Viewed）**：当日浏览量最高的前 100 张画作。
  - **服务端自动候选降级**：当宽泛的 `order:score` 查询偶尔波动超时，服务端自动无缝切换为追加 `status:active` 过滤重试，杜绝页面整页空白。

### 3. 多维分级体系与智能标签筛选
- **四档分级独立抓取与硬过滤**：
  - 细分为 **全年龄 (g - General)**、**敏感 (s - Sensitive)**、**较敏感 (q - Questionable)**、**成人 (e - Explicit)**。
  - **并发分级采集**：每个勾选分级独立申请足量抓取配额（每级 36 张），避免传统多选平分导致每级仅有几张图的缺陷；拉取后前端进行二次精确校验过滤，坚决杜绝脏数据溢出。
  - 支持“一键全选”及“至少保留一项”防空保护。
- **动态热门标签栏（Tag Bar）**：
  - 从 Danbooru `/tags.json` 动态获取高频使用量标签，附带发帖数量展示与 6 小时服务端内存缓存。
  - **深度汉化支持**：内置常用二次元标签的中英对照字典，不懂英文标签也能顺畅检索。
  - 标签栏支持多选高亮、一键清空、实时统计与折叠展开。
- **智能搜索解析**：
  - 自动规避复制转义陷阱：用户从 Markdown 或聊天软件复制带有反斜杠转义的标签时，系统自动规范化为 Danbooru 接受的原生格式。

### 4. 本地收藏与有词区工作流
本地收藏不往 Danbooru 远端同步，保存在本地服务端磁盘；同一局域网设备可共享。待反推只承担临时缓存和 AI 队列，提示词写入成功后自动进入有词区。

```
[日常刷图] ──♥ 收藏──> 【原始收藏 (Original)】
                             │
                      [AI] 移入待反推
                             │
                             ▼
                    【待反推 (Pending)】
                    ┌───────────────────────────┐
                    │ 1. 后台串行自动缓存高清原图 │
                    │ 2. 选择反推预设风格       │
                    │ 3. 外部 Agent/Codex 批量反推│
                    │ 4. 写入提示词 (Prompt)    │
                    └─────────────┬─────────────┘
                                  │
                               [释放]
                                  │
                                  ▼
                    【已完成 (Completed)】
                    (高清图与优质提示词永久沉淀)
```

- **第一栏：原始收藏 (Original)**：
  - 刷图时点击卡片心形图标即可沉淀到此；
  - 智能排版算法：**横屏宽图优先显示在顶部**，视觉体验更佳；
  - 卡片左下角配备 **AI** 按钮（移入待反推）与 **完成标记** 按钮。
- **第二栏：待反推 (Pending)**：
  - **后台高清图异步缓存**：一旦移入，Node 服务在后台缓存 Danbooru 的 `large_file_url` 到本地 `data/favorites/pending/` 目录，缓存就绪前以遮罩标识，失败可一键“重试缓存”。
  - **反推预设体系**：内置 **动漫专用、动作扩写、艺术导演扩写、巨构提示词、瑶光真人、通用扩写、随机** 等丰富预设，支持卡片独立指定。
  - **队列管理**：支持卡片加入/移出反推队列（`autoEnabled` 开关与 `queueOrder` 严格编号）。
  - **状态灯指示**：红灯（缓存/反推失败，点击即刻重试）、绿灯（反推成功）、黄/灰色（排队与缓存中）。
  - **安全“释放”机制**：只有当“高清原图已本地缓存”且“提示词反推成功（字符满足最低长度阈值）”后，“释放”按钮才会激活。点击后，图片与提示词移入已完成，磁盘上的原图文件自动安全转移至 `data/favorites/completed/`。
- **第三栏：已完成 (Completed)**：
  - 最终归档库，展示高清原图与高质量反推提示词；
  - 支持一键复制提示词、弹窗查看全文，随时可逆回退到原始收藏。

### 5. ComfyUI 图片元数据提取与解析
DFlow 内置专属的「元数据 (Metadata)」模块，彻底解决 AI 创作者“看到一张图不知道工作流怎么搭”的痛点：

- **纯原生二进制解析（零额外依赖）**：
  - 底层基于 Node.js 原生 `Buffer` 与 `node:zlib.inflateSync`，秒级解析 PNG 的 `IHDR`、`tEXt`、`iTXt`、`zTXt` 关键数据块，单张最大支持 **80MB** 超大图导入。
- **深度兼容与智能解析**：
  - **ComfyUI API 拓扑解析**：递归遍历节点连接树（Link Traversal），顺藤摸瓜定位到与 KSampler 直接或间接绑定的 CLIPTextEncode 正反提示词输入节点。
  - **ComfyUI Workflow 解析**：当图片仅存工作流界面数据时，智能从各节点的 `widgets_values` 中提取采样器、步数与模型名。
  - **A1111 / SD-WebUI 兼容**：兼容解析经典 SD-WebUI 的 `parameters` 文本格式。
  - **LoRA 强力侦测**：全面支持标准 `LoraLoader`、`LoraStacker`、`Power Lora Loader` 等多种主流 LoRA 加载节点的名称与权重（Strength）提取。
- **结构化参数一览**：
  - **底模（Model）**：Checkpoint 名称、UNET 名称；
  - **LoRA 清单**：展开折叠显示各 LoRA 名称及模型权重；
  - **生图核心参数**：步数 (Steps)、CFG Scale、采样器 (Sampler)、调度器 (Scheduler)、随机种子 (Seed)、降噪幅度 (Denoise)；
  - **提示词操作**：正反向提示词查看、一键复制、原图放大与本地删除。

### 6. 局域网多端同步与跨设备协同
- **主机运行，全屋共用**：
  - 电脑启动服务后，同一 Wi-Fi / 局域网内的手机、平板、笔电直接通过浏览器打开 `http://电脑局域网IP:4173`。
- **统一数据中枢**：
  - 服务端统一维护 `data/dflow-state.json`，多设备共享同一份收藏夹、Danbooru 凭据与浏览偏好（选中的榜单、列数、分级、搜索词、选定标签）。
- **即时与增量轮询机制**：
  - 本机修改即时写入；其他已打开的设备每 10 秒轻量级增量对比 `updatedAt` 时间戳，发现变化无感刷新同步。
- **端设备自适应响应式**：
  - 手机端自动单/双列自适应排版，大屏电脑端支持宽屏多列并排。

---

### 7. 智能抗限流与图片代理通道
- **服务端防封节流（Paced Fetch）**：
  - Danbooru 对接口并发有严格的限流策略。DFlow 服务端设计了串行请求队列，默认保证 1800ms 的安全请求间隙。
  - 遇到 HTTP 420 / 429 限流时，智能解析 `Retry-After` 头，并使用指数退避算法进行熔断冷却，防止 IP 被拉黑。
- **图片专用 CDN 4 并发槽位**：
  - 瀑布流进入视口时图片突发流量极大，DFlow 设立了独立的图片代理通道（最多 4 并发），平滑请求速率并设置 24 小时缓存头。
- **Cloudflare Quick Tunnel 方案**：
  - 针对直接使用 Cloudflare Worker 代理 Danbooru 会被机房出口 IP 403 拦截的问题，DFlow 保留本地 Server，提供本地电脑运行 + Cloudflare 临时隧道方案，轻松实现外网免公网 IP 安全访问。

## 三、技术栈与系统架构

### 1. 技术栈选型
- **后端运行环境**：Node.js (>= 18.0.0, ES Module 原生模式)
- **服务端框架**：Express 5.x（极简 HTTP 路由、静态托管、流媒体代理）
- **核心底层库**：`node:fs`、`node:path`、`node:crypto`、`node:zlib`（原生 PNG 解压与元数据提取，无任何重型图像第三方 C++ 依赖）
- **前端架构**：原生 HTML5 + 现代 Vanilla JavaScript + 原生 CSS3 Flex/Grid（无构建打包步骤，所见即所得）
- **数据持久化**：本地 JSON 文件存储 (`dflow-state.json`, `index.json`) + 磁盘图片文件目录结构

### 2. 系统架构图

## 四、安装启动与使用指南

### 1. 环境要求
- **操作系统**：Windows / macOS / Linux
- **运行环境**：[Node.js](https://nodejs.org/) `>= 18.0.0`
- **网络条件**：能正常访问 Danbooru 网络环境（若处在受限网络，请配置主机代理或环境变量）

### 2. 一键启动 (Windows)
在项目根目录下，双击运行 **`start.bat`**。
脚本会自动检测并执行 `npm install`，随后自动拉起浏览器并访问 `http://127.0.0.1:4173`。

### 3. 命令行安装与启动
```bash
# 1. 进入项目目录
cd dflow

# 2. 安装极简依赖 (仅 express)
npm install

# 3. 启动本地服务
npm start

# 开发模式 (Node 18+ 原生文件监听热重启)
npm run dev
```
终端输出如下提示即代表启动成功：
```text
DFlow 已启动：http://0.0.0.0:4173
```

### 4. 局域网访问与远程穿透
- **同一局域网访问**：
  1. 在电脑端打开终端输入 `ipconfig` (Windows) 或 `ifconfig` (macOS/Linux) 查看局域网 IP（例如 `192.168.1.100`）；
  2. 手机或平板连接相同 Wi-Fi，直接用浏览器访问：`http://192.168.1.100:4173` 即可同步刷图。
  *(注：若移动端打不开，请检查系统防火墙是否放行了 Node.js 4173 端口)*。
- **免公网 IP 远程访问（Cloudflare Quick Tunnel）**：
  若想在室外通过 5G 手机访问家中电脑的 DFlow，请在电脑端运行：
  ```bash
  cloudflared.exe tunnel --url http://127.0.0.1:4173
  ```
  终端将生成临时公网地址（`https://xxxx.trycloudflare.com`），手机打开即可直接访问。具体详见 `README_403_WORKAROUND.md`。

### 5. Danbooru 账号配置 (可选)
DFlow 在**不登录任何账号的情况下完全可用**。如果您拥有 Danbooru 账户：
1. 点击右上角 **「登录」** 按钮；
2. 输入 **账户名称** 与 **Personal API Key**（在 Danbooru 个人资料 -> API Keys 页面生成）；
3. 点击 **「测试登录」** 确认有效后点击保存；
4. 凭据将安全保存在本地服务端，局域网内所有设备自动共用该凭据，享有更高的 API 配额与检索权限。

### 2. AI 提示词反推自动化流程 (搭配 Krea2 通用版 Skill 自动反推)

DFlow 不仅支持在网页端管理待反推队列，还提供了与 AI Agent（如 Antigravity、Codex、Claude 等）联动的全自动批量反推能力：

#### 📥 1. 获取与安装配套 Skill
- **下载地址**：前往项目的 [GitHub Releases 页面](https://github.com/oldiron-666/Dflow/releases) 下载配套的 [**`krea2-general-export.zip`**](https://github.com/oldiron-666/Dflow/releases/latest)。
- **安装方式**：
  - 解压缩包，将其中的 `krea2-general/` 文件夹放入对应 AI 工具的技能目录：
    - **Antigravity / Gemini CLI**：`~/.gemini/antigravity/skills/krea2-general` 或 `~/.gemini/config/skills/krea2-general`
    - **Codex**：`~/.codex/skills/krea2-general`
  - 该 Skill 内置《通用反推》与《通用扩写》双参考标准，专为 DFlow 队列无缝调度定制。

#### 🔄 2. DFlow 本地队列准备
1. 刷图时点击卡片左下角的 **`AI`** 按钮移入「待反推」；
2. 服务端在后台串行下载 Danbooru 高清大图至 `data/reverse/pending/`（卡片显示缓存状态）；
3. **预设选择**：在待反推卡片的预设下拉菜单中选择 **「通用扩写」**（Skill 会校验预设必须为通用扩写，严禁假冒其他风格）；
4. 确保卡片右下角的自动反推开关（绿标）开启。

#### 🤖 3. 唤醒 AI 自动批量反推
直接向已加载该 Skill 的 AI 助手发送指令（例如：*“启动 DFlow 自动化反推”*）：
1. **自动探测**：Skill 自动运行 `node scripts/reverse-cli.mjs status` 探测本地 DFlow 服务状态，汇总并向您汇报当前待反推总数与可领取数；
2. **确认执行**：在您确认开始后，Skill 逐张调用 `node scripts/reverse-cli.mjs next` 领取任务；
3. **视觉反推与扩写**：AI 仔细观察本地高清缓存图，严格区分客观事实与合理推测，完成高质量的完整通用扩写提示词（确保达到标准长度与描述丰富度）；
4. **自动回写验证**：调用 `node scripts/reverse-cli.mjs complete <ID> <PROMPT_FILE> 通用扩写` 自动写回系统；前端卡片立即亮起绿灯，提示词就绪。

#### 🚀 4. 释放至已完成归档
提示词就绪且大图缓存就绪后，点击卡片右上角的 **「释放」** 按钮，系统自动将高清缓存大图永久迁移至 `data/favorites/completed/`，图片与反推提示词归档至「已完成」专栏，随时可展开查看或一键复制。

---

#### 🛠️ 附：自动化命令行接口 (reverse-cli.mjs) 说明
如果需要自研脚本或二次开发，可直接调用内置 CLI：
```bash
# 查看待反推队列状态与可执行数量
node scripts/reverse-cli.mjs status

# 领取队列中下一张待反推任务 (状态自动转为 processing)
node scripts/reverse-cli.mjs next

# 将生成的提示词回写至本地系统 (需指定卡片 ID、提示词文本路径及预设)
node scripts/reverse-cli.mjs complete <ID> <PROMPT_FILE_PATH> 通用扩写

# 标记某张图片反推失败并记录原因
node scripts/reverse-cli.mjs fail <ID> <REASON>
```

### 2. 有词卡片、手写与提示词窗口

- 榜单和本地收藏任意子栏可对图片右键选择「创建提示词卡片」：使用当前图片与已有提示词打开编辑窗口。保存后未收藏的先收藏，原有收藏则从原始/待反推/已完成移动到有词区，不复制出第二张收藏。手写卡片在待反推或已完成也可右键编辑并移回有词区。
- 有词区不区分手写或 AI 来源，统一使用气泡式复制/展开、图片上的 AI 入口、释放至已完成以及卡片右下角的删除操作。提示词窗口左侧可直接粘贴/拖入替换当前图片，无需卡片上的替换按钮；新建手写窗口不显示复制和修改按钮。
- 取消本地收藏或删除手写卡片时，服务端同时删除对应本地缓存图片。撤销收藏会重新缓存，删除操作本身不删除 Danbooru 上的图片。

- 待反推中已有提示词的旧卡片启动时迁移到「有词区」；迁移前自动备份状态与旧手写索引。AI 完成写回以及待反推卡片手动保存提示词，都会将卡片及高清缓存移入有词区。
- 本地收藏的任意子目录可点击「手写提示词」，也可从电脑拖入 PNG/JPEG/WebP 图片直接打开编辑窗口；先粘贴提示词，再粘贴/拖入图片，或填写没有图片时的文字概述。保存后统一进入有词区。
- 展开提示词时，左侧固定尺寸显示图片，中间可直接编辑提示词；「修改提示词」按需打开右侧中文翻译栏。「修正翻译」只在点击后执行，不会每次输入都翻译。
- 元数据库只通过顶部入口导入和读取含生成元数据的 PNG，不再创建手写卡片。旧手写卡片保留内容并迁移到有词区。

### 3. ComfyUI 原图导入与参数复用
1. 点击顶部 **「元数据库」**（位于「本地收藏」右侧）；
2. 点击 **「导入 ComfyUI PNG」**，可多选拖入本机通过 ComfyUI 或 WebUI 生成的原画文件；
3. 系统瞬间解析并在前端生成卡片：
   - 查看底模与所有挂载的 LoRA 权重；
   - 查看 CFG、采样器、调度器、种子；
   - 点击 **「复制提示词」** 直接黏贴到生图工具中快速复现实验。

## 六、注意事项与常见问题

> [!IMPORTANT]
> **关于图片导入**：ComfyUI 元数据提取功能依赖于 PNG 文件内置的元数据块。从微信、QQ、微博或各大社交网站转存的缩略图通常已被二次压缩转码并剔除了生成信息，请务必导入本地保存的原始 PNG 文件。

> [!NOTE]
> **剪贴板兼容性**：各大操作系统与现代浏览器的 Clipboard API 原生主要支持 `image/png` 格式。当你在 DFlow 中复制 JPEG 或 WebP 画作时，系统会在本机后台自动将图片位图转为标准 PNG 格式后再推入剪贴板。若复制失败，请检查浏览器是否允许当前站点的剪贴板写入权限。

> [!WARNING]
> **本地数据安全**：所有配置与收藏均保存在本地 `data/dflow-state.json` 中。请注意定期备份 `data/` 目录；如果填写了个人 Danbooru API Key，切勿将 `data/` 目录上传至公开代码仓库或分享给他人。

### 提示词直接修改与 Google 翻译

- 展开卡片提示词后，英文框本身就是文本框；改完点击「保存修改」（或 Ctrl+S），会保存到对应收藏/元数据库。关闭而未保存的改动不会写入。
- 右侧「修改提示词」仍是按「修正翻译」才翻译改动片段；首次展开需要把已有英文译为中文。
- 默认使用 Google 的非官方网页翻译端点。它可能对服务器 IP 返回 HTTP 429；即使翻译短句也失败时，不是提示词长度问题，无法靠继续拆句保证可用。
- 如果**自行选择使用可能计费的官方 Google Cloud Translation API**，先在 Google Cloud 启用 Cloud Translation API、配置结算并创建受限 API Key，然后在启动 DFlow 的服务器环境中设置 `GOOGLE_TRANSLATE_API_KEY` 并重启服务。密钥仅在服务器环境变量中使用，不要填写在网页登录框，也不要写入仓库。未设置时仍走原有网页端点；程序不会自动开通付费服务。
