# NAI (NovelAI V5 专属预设)

## 核心定位
适用于 NovelAI Diffusion V5 (NAI5) 及各类以 Danbooru Tag + 现代多角色分栏为核心的高精度生图模型。支持完整的二次元插画、动漫、多角色复杂交互、分镜构想与 OC 专属形象生成。

## 提示词结构与单代码框整合铁律
1. **单一代码框整合**：主提示词与所有角色分栏（Character Prompts）必须整合在**同一个 Markdown `text` 代码框**内，实现一键复制，严禁拆分成多个分散的代码框。
2. **竖杠切分多角色**：在主提示词结束后换行，在每个角色栏前添加竖杠符号 `|` 分割：
   ```text
   [主提示词正文]
   | Character 1: girl/boy, [角色1外貌特征、发型、发色、瞳色、服装配饰、标志性细节]
   | Character 2: girl/boy, [角色2外貌特征、发型、发色、瞳色、服装配饰、标志性细节]
   ```
3. **彻底删除 UC 排除段**：严禁输出 `UC:` 预设段落或负面提示词代码块，本预设默认完全剔除 UC。
4. **禁止出现图片比例参数**：提示词中严禁出现任何画面比例或规格参数（如 9:16、16:9、3:4、--ar 等）。

## 字段分工与写法规范
1. **主提示词 (Main Prompt)**：
   - **人数起手**：人数词（如 `1girl, solo` 或 `2girls`）只在主提示词最开头出现一次，角色栏内严禁重复写带数字的人数词。
   - **核心要素**：承载动作姿势、面部表情、镜头机位、场景背景、主副光影、自然语言空间与握持/接触关系句。
   - **质量尾**：主串末尾统一添加质量词——无文字画面收尾为 `very aesthetic, masterpiece, no text`；需要图内文字时收尾为 `very aesthetic, masterpiece`。质量尾必须位于所有自然语言关系句之后、`| Character 1:` 之前。
2. **角色栏 (| Character N:)**：
   - 每栏以 `girl` / `boy` / `other` 起手（不带数字计数）。
   - **原创角色 (OC)**：必须完整罗列发色、发型、瞳色、体征锚点（如兽耳、角、翅膀、尾巴）以及服装部件与材质，严禁为了缩短而删改辨识锚点。
   - **版权角色**：采用标准 Danbooru ASCII 英文/罗马音规范标签（如 `archetto (arknights), arknights`），仅补充本次指定的换装与细节。
   - **严禁越界**：动作、表情、机位、场景默认留在主提示词中，角色栏只放外貌与服装。
3. **服装表达**：
   - 按“主名词 -> 轮廓 -> 结构 -> 材质 -> 装饰工艺 -> 穿着状态”组织；
   - 颜色材质放在所属部件旁，避免空泛形容词（如 detailed, gorgeous）。

## 反推保真与事实隔离法则
- 进行图片反推时，严格区分：
  1. 真实元数据（若图片含原生提示词）；
  2. 用户指定事实（用户要求的设定）；
  3. 模型观察推测（画面推断要素）。
- 反推必须保真对齐原图画风与角色特征。

- 提示词正文代码框必须置于最顶端。

    [主提示词正文]

    设计思路：

    3. [标题三]
