# 工作模式指南

本技能（AIprompt）包含创建、反推与灵感三种模式。提示词预设属于正式提示词流程，不是额外模式。

## 通用语言与输出规则（纯英文提示词铁律）

- **正式提示词全英文输出**：所有正式生成的最终提示词正文一律强制使用纯英文（English），严禁在代码框正文中出现任何中文字符。
- **外部结构语言**：面向用户的框架内容（观察点、不确定项、设计思路标题、提示词翻译、预设名）使用中文，代码框包裹的提示词正文必须为纯英文。

## 1. 创建（`create`）

根据概念、用途、审美方向和硬性要求，组织主体、动作、空间、镜头、环境、光影、色彩、材质和风格，输出一个纯英文正式提示词。

## 2. 反推（`reverse`）

根据一张或多张图片进行反推时，先提炼可见事实与不确定项。随后无缝接入扩写预设流程（若用户未指定预设，通过交互弹窗让用户点选预设，**`nai` 始终为第一选项**），使用选定预设执行全量深度扩写。

## 3. 灵感（`inspiration`）

灵感模式只用于找方向，默认给出 5 个不同方向的简短中文概要，不生成正式提示词。输出完毕后用户选定方向，通过交互弹窗点选预设进入正式创建流程。

## 4. 预设选择顺序与 NAI 规范

弹窗选项严格按照以下顺序展示：
1. **`nai`**
2. **`海报`**
3. **`插画`**
4. **`电影`**
5. **`巨构提示词`**

当选择 `nai` 时：
- 主串与多角色分栏统一整合在顶部的**单一代码框**内，角色前用换行加竖杠 `\n| Character N:` 分割；
- 彻底剔除 UC 排除段；
- 严禁出现比例规格参数；
- 版权角色使用标准 Danbooru ASCII 标签，OC 角色罗列完整外貌特征锚点。

## 正式输出

正式创建默认输出：
- [预设名] 与其下独立 `text` 代码框中的纯英文完整提示词（置于最前）；
- 代码框外的中文设计思路标题；
- 文末“提示词翻译：”另起一行附上不被代码框包裹的提示词中文翻译，空行与换行格式与英文正文保持严格一致。

正式反推默认输出：
- [预设名] 与其下独立 `text` 代码框中的纯英文完整提示词（置于最前）；
- 代码框外的观察结果；
- 代码框外的不确定项；
- 代码框外的中文设计思路标题；
- 文末“提示词翻译：”另起一行附上不被代码框包裹的提示词中文翻译，空行与换行格式与英文正文保持严格一致。

用户明确说“只给提示词”时，只输出提示词代码框。
