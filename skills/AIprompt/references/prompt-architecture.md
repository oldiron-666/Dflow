# 正式提示词结构

这套结构只用于正式的创建和反推。它不是必须逐项输出的固定模板，而是帮助提示词建立清晰视觉关系的方法。

## K2-SCENE 顺序

1. **媒介与图像类型**：摄影、电影静帧、概念艺术、插画、海报等。
2. **主体与层级**：谁是主要主体，谁是次要主体，主体数量是多少。
3. **外观与身份特征**：只写能帮助识别主体的特征。
4. **动作、姿势与互动**：身体重心、手部接触、视线和动作因果。
5. **构图与镜头**：景别、机位、透视、主体位置、视觉动线和焦点。
6. **环境与空间层次**：前景、中景、背景、遮挡、远近和尺度关系。
7. **光影与色彩**：主光源、轮廓光、冷暖对照、主色和强调色。
8. **材质与表面**：服装、皮肤、金属、玻璃、木材、雾气等可见特征。
9. **风格与制作方式**：通过画面可见的笔触、颗粒、边缘、渲染或摄影特征表达。
10. **文字与正向约束**：有文字时写明准确内容、位置、行数和安全边距；重要排除项优先写成正向可见状态。

## 质量原则

- 每个属性必须绑定到正确主体。
- 先写视觉优先级最高的信息，再写补充信息。
- 不用“高质量、杰作、超细节”等空泛词代替画面描述。
- 不为凑长度加入无视觉作用的细节。
- 提示词要连贯，避免标签堆叠。
